# NEUROATLAS 2.1 — brain-study

Интерактивный образовательный атлас мозга: Three.js, 10 отделов, 5 уроков, 8 вопросов, адаптивный интерфейс и резервная процедурная 3D-схема.

## Запуск

```bash
npm install
npm run dev
```

Для сборки: `npm run build`. Результат — `dist/`.

## GitHub Pages (`prov-ori/brain-study`)

1. Загрузите **содержимое этой папки** в корень ветки `main` репозитория `prov-ori/brain-study` (не вложенную папку).
2. Откройте `Settings → Pages → Build and deployment → Source` и выберите **GitHub Actions**.
3. Перейдите в `Actions`; workflow `Deploy NEUROATLAS to GitHub Pages` выполнит `npm install`, `npm run build` и опубликует `dist`.
4. Откройте `https://prov-ori.github.io/brain-study/`.

В `vite.config.js` уже указан правильный `base: '/brain-study/'`. Для другого имени репозитория поменяйте base. GitHub Actions устанавливает зависимости автоматически. После первого локального `npm install` рекомендуется добавить полученный `package-lock.json` для воспроизводимых сборок.

## 3D-модель

Проект **работает без стороннего GLB**: по умолчанию показывает встроенную **учебную схему** мозга. Это **не гиперреалистичная и не медицински достоверная модель**; формы и расположение внутренних структур приблизительны.

Для подключения реальной анатомической модели поместите GLB в `public/models/brain.glb`. Внешний файл должен содержать **раздельные именованные meshes** вроде `frontal`, `frontal_l`, `temporal`, `cerebellum`, `brainstem`, `thalamus`, `hippocampus`, `amygdala`, `corpus_callosum` и так далее. От одного монолитного mesh выделение отделов невозможно. **Проверьте соответствие имён и анатомических границ**, прежде чем использовать реальную модель в образовании. Текущий загрузчик ожидает обычный GLB без дополнительных Draco-расширений.

Для внешнего GLB убедитесь, что лицензия позволяет его размещение и распространение. Модель в архив не входит.
