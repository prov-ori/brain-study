# NEUROATLAS — интерактивная платформа нейроанатомии

Одностраничная учебная платформа на русском языке. Содержит интерактивную 3D-модель, карточки 10 ключевых областей, мини-уроки, тесты из 8 вопросов, список избранного и управление прозрачностью и полушариями.

## Запуск

1. Нужен браузер с поддержкой WebGL и **интернет-соединение**: Three.js, декодер Draco и открытая анатомическая модель загружаются по сети.
2. Откройте `index.html` в браузере. Если браузер ограничивает модульные запросы из `file://`, запустите локальный сервер в каталоге проекта:

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080/`.

## Управление

- Мышь/касание: вращение.
- Колёсико/жест разведения пальцев: масштаб.
- Правая кнопка мыши: перемещение модели.
- Нажатие на область: выбор и показ русскоязычной карточки.
- Кнопки «Прозрачность» и «Левое / Правое»: визуальные фильтры.
- Мини-уроки и тест доступны из навигации.

## Источники и лицензия модели

3D-модель загружается при запуске из открытого проекта [Brain Project](https://github.com/itayinbarr/brainproject), основанного на материалах **Z-Anatomy**, **BodyParts3D / DBCLS** и открытых нейровизуализационных атласах. 3D-геометрия и её метаданные: **Creative Commons Attribution-ShareAlike 4.0 (CC BY-SA 4.0)**, © участники Z-Anatomy и BodyParts3D / DBCLS. Если вы распространяете модифицированную модель, необходимо соблюдать условия лицензии CC BY-SA 4.0 и сохранять атрибуцию. Код NEUROATLAS написан отдельно; лицензия на исходную модель не меняется.

Это **образовательная**, а не диагностическая модель: некоторые глубокие ядра и проводящие пути реконструированы приближённо. Структуры модели соотносятся с учебными областями алгоритмически; границы долей могут быть не полностью покрыты и не предназначены для клинического использования.

Для запуска можно также выполнить `python3 start_server.py` (или `python start_server.py` в Windows). Скрипт откроет страницу в браузере.
