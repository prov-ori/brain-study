# NEUROATLAS 2.0

Исходники обновлённого 3D-просмотрщика мозга на Three.js и Vite.

## Запуск

1. Установите Node.js 20.19+ (или совместимую актуальную версию).
2. Выполните `npm install`.
3. Поместите совместимую модель в `public/models/brain.glb`.
4. Выполните `npm run dev` и откройте локальный адрес, указанный Vite.

Для сборки: `npm run build`. Папка `dist/` подходит для публикации на Vercel.

## Важное ограничение

Файл `brain.glb` **не входит в архив**. Без него приложение отображает понятное сообщение об ошибке вместо мозга. Геометрия, детализация, лицензия и анатомическая точность модели должны быть проверены отдельно. Имена mesh-объектов в `MODEL_STRUCTURE_MAP` — **пример**, а не подтверждённая привязка к вашей конкретной модели. Проверьте имена в консоли браузера и исправьте таблицу сопоставления в `src/main.js`.

В данном комплекте есть просмотрщик и API сохранения прогресса. Полные уроки и тесты ещё не реализованы.
