# NEUROATLAS 3.0

Русскоязычный учебный 3D-атлас мозга. Модель включена: 437 именованных структур,
4,65 МБ, Draco GLB; отдельные извилины и борозды, внутренние отделы, сосуды и нервы.
Фиктивная процедурная подмена удалена. При ошибке загрузки показывается ошибка.

## Готовая сборка из ZIP
Нужен Node.js 22.12+ (или 20.19+). Распакуйте ZIP и запустите START-WINDOWS.cmd
или `node scripts/serve.mjs`. Откройте http://127.0.0.1:4173/brain-study/.
Папка dist включена в ZIP. Двойной щелчок по index.html не подходит: GLB загружается по HTTP.

## Разработка
`npm ci`, затем `npm run dev`.
`npm test` — логика обучения, поиск, сопоставление структуры модели и метаданных.
`npm run check:model` — glTF Validator и декодирование всех Draco-мешей.
`npm run build` — production-сборка.
`npx playwright install chromium`, затем `npm run test:e2e` — браузерные тесты
готовой сборки (WebGL, выбор и слои, сохранение урока, два полных теста,
мобильный экран и ошибка отсутствующей модели).

## GitHub Pages
Ветка main автоматически проходит проверки и публикуется через .github/workflows/deploy.yml.
В Settings → Pages должен быть выбран источник GitHub Actions.
URL: https://prov-ori.github.io/brain-study/.
Vite base по умолчанию /brain-study/. Для другого пути задайте VITE_BASE_PATH
перед сборкой. Все ресурсы используют этот префикс; модель и декодер локальные.
package-lock.json включён; Actions использует npm ci.

## Управление
Перетаскивание — вращение, колесо/жест — масштаб, ПКМ — панорамирование.
Список и десять быстрых областей доступны с клавиатуры. Фокус приближает
выбранное, изоляция скрывает остальные структуры. Прозрачность коры помогает
увидеть внутренние отделы. Выбор полушария сохраняет срединные структуры.
Поиск понимает английские имена источника, русские названия разделов и десяти
основных областей. Полный медицинский перевод всех 437 имён не заявляется.

## Происхождение и границы достоверности
Это подробная анатомическая геометрия Z-Anatomy / BodyParts3D в экспорте
Brain Project (Itay Inbar), а не фотографический 3D-скан. Фототекстур нет.
Называть её гиперреалистичным препаратом было бы неверно. Мелкие глубинные
структуры частично зарегистрированы из других атласов с приблизительным
совмещением; независимая медицинская экспертиза не проводилась.
См. public/models/ATTRIBUTION.md, UPSTREAM-LICENSE.txt и REGISTRATION.md.
Модель и метаданные — CC BY-SA 4.0; лицензии и авторство сохранены в сайте и ZIP.
Изменения материалов отображения также распространяются по CC BY-SA 4.0.
Учебные тексты не заменяют медицинское образование или диагностику.

Краткие учебные описания сопоставлены со справочным материалом Johns Hopkins:
https://www.hopkinsmedicine.org/health/conditions-and-diseases/anatomy-of-the-brain

## Совместимость со старым режимом Pages
Исходный HTML Vite расположен в src/index.html, JavaScript — в src/main.js.
В корне репозитория лежит готовая статическая версия: index.html, assets/,
models/, draco/, licenses/ и .nojekyll. Она работает и в режиме публикации ветки,
поэтому параллельная старая сборка Pages больше не отдаёт необработанный код.
Команда npm run build обновляет dist/ и статическую копию в корне автоматически.
GitHub Actions продолжает тестировать и публиковать dist/. Для чистого нового
репозитория предпочтителен источник GitHub Actions, но текущий комплект
совместим с обоими режимами без ручной перенастройки Pages.
